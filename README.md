# Колесо — жребий на бумаге

Статический сайт: колесо-рулетка для случайного выбора. Чистые HTML, CSS и JavaScript (ES-модули), без сборки, фреймворков и внешних CDN. Размещается на GitHub Pages.

## Где лежат данные

Всё хранится в вашем браузере, на сервер ничего не уходит:

- **localStorage**, ключ `wheel:v1:state`: колёса, варианты, цвета, история, выбывшие, настройки, активное колесо, тема, громкость. Если данные повреждены, копия сохраняется под `wheel:v1:corrupt`, а колёса сбрасываются к демо-набору.
- **IndexedDB**, база `wheel-media`, хранилище `blobs`: аудио и картинки (ключи `<id колеса>:audio` и `<id колеса>:image`).

Данные привязаны к браузеру и домену. На другом устройстве, в другом браузере или на другом адресе колёса не появятся: синхронизации нет намеренно. Между вкладками одного браузера изменения подтягиваются автоматически.

«Сбросить всё» (шестерёнка в шапке) стирает и localStorage, и IndexedDB этого сайта.

## Лимиты

| Что | Предел |
| --- | --- |
| Колёс | 30 |
| Вариантов на колесе | 200 |
| Записей в истории колеса | 50 |
| Аудиофайл | 15 МБ |
| Картинка | исходник до 40 МБ, внутри сжимается до 1600 px (WebP или JPEG) |
| Длительность прокрутки | 3–20 с (при подгонке под трек — 3–30 с) |

В приватном режиме браузер может закрыть localStorage и IndexedDB. Сайт продолжит работать, но вверху появится плашка: после закрытия вкладки данные пропадут.

## Офлайн

`sw.js` кэширует файлы сайта при первом заходе (по https или на localhost). Дальше сайт открывается без сети.

## Шрифты (необязательно)

Сайт выглядит нормально и без них: заголовки упадут на Rockwell, Roboto Slab, Georgia, цифры и метки — на системный моноширинный. Чтобы получить задуманный вид, положите в `fonts/` файлы `.woff2` с кириллицей (лицензия OFL):

| Файл | Шрифт |
| --- | --- |
| `Bitter-ExtraBold.woff2` | Bitter, начертание ExtraBold (800) |
| `IBMPlexMono-Regular.woff2` | IBM Plex Mono Regular (400) |
| `IBMPlexMono-Medium.woff2` | IBM Plex Mono Medium (500) |

Скачать можно на Google Fonts (Bitter, IBM Plex Mono) с подмножеством `cyrillic` или на fontsource.org. Имена файлов должны совпадать с таблицей.

## Структура

```
index.html
sw.js
css/style.css
js/main.js      точка входа
js/state.js     модель данных, действия, подписка
js/storage.js   localStorage, IndexedDB, миграции, debounce-сохранение
js/wheel.js     canvas, физика вращения и флажка
js/audio.js     Web Audio: тики, победный звук, пользовательская музыка
js/media.js     проверка и сжатие файлов, drag&drop
js/ui.js        DOM, панели, диалоги, тосты, талон
js/confetti.js  конфетти
fonts/          необязательные .woff2
```
